## CD-SCOPE-001：主网调度与直接受令单位

- 成都网络发令调度管辖分为主网、配网。
- 用户明确的主网发令单位：`成都地调`。
- 用户提供的直接受令单位查询：

```sql
SELECT SLORGANNAME
FROM SCCDWLXL_OPCARD.TH_DC_DCMS_ORGANDISPREL
WHERE FLORGANNAME = '成都地调';
```

- `FLORGANNAME` 为发令单位名称；`SLORGANNAME` 为受令单位名称。
- 2026-09-18 只读元数据检查还确认该表有 `FLORGANID`、`SLORGANID`、`KEYID` 列。做账号/单据关联时应核对 ID，不仅依赖显示名称；具体业务映射仍需确认。
- 查询只代表当前配置的直接关系，不应冻结成永久单位名单，也不应自动扩展成所有后代单位。

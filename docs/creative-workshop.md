# 创意工坊（Beta.11）

入口为左侧「创意工坊」，所有登录用户可使用。系统自带、个人设计、公共壁纸、使用排行和我的记录分开呈现。

## 从想法到上线

1. 选择系统主题作为基础，填写作品名称和描述，可附 PNG/JPEG/WebP 参考图。
2. 本机执行器调用当前账户的原生 imagegen，输出完整工作台设计预览。可以继续提意见并引用历史版本，多轮记录保留。
3. 制作者确认设计后进入制作。原生 imagegen 分别生成纯壁纸背景和完整预览图，保留现有业务布局和独立的 3D 小球组件。
4. 制作版本可以临时试用、继续修改；制作者确认效果后才正式上线。使用后台动态资源目录，不修改应用源码、VERSION，不要求重启或发布新应用版本。
5. 上线后出现在个人设计，选择使用后绑定账户。换浏览器重新登录仍恢复个人壁纸。旧上线版本在新版本确认前继续可用。
6. 「公开给所有用户」是独立确认操作，只公开上线版本的背景和预览图，不公开参考图、设计讨论或历史版本。公开资源可能被下载或缓存。

公开推荐链接直接进入公共壁纸。私人作品链接只允许本人和管理员查看；只有本人可修改、确认、上线和公开。

## 运行与通知

- imagegen 使用本机执行器已验证支持的原生能力及平台模型/思考深度配置；不需要单独的图片 API 密钥，不会悄悄切换其他付费服务或生成占位图。
- 请求持久化入队，关闭浏览器不会丢失已提交请求。生成中可以继续编辑下一轮意见，轮询不覆盖输入。
- 失败记录保留，可重试；执行器心跳失联超过 5 分钟标记失败，迟到结果不能覆盖新状态。工坊最多占一个执行器并发槽位。
- 上线资源写入 `autodev-static/workshop/作品ID/版本ID/`，不受 `autodev/` 交付包的三天清理影响。私人资源设置独立 private ACL 和限时签名；公开后使用 public-read 永久地址。上传后读取校验通过才激活，OSS 故障不覆盖正在使用的版本。
- 制作者及启用的管理员收到上线邮件，每个邮箱独立投递并保留任务记录。推荐邮件由制作者主动确认发送，按用户/上线版本去重排队，用户可取消订阅；关闭订阅的用户不会收到后续推荐。邮件失败不撤销已上线壁纸，可单独重试。

## 使用统计与性能

- 按账户记录预览、设为个人壁纸和打开工作台。同一用户每天的访问/预览去重；重复保存相同壁纸不增加选择次数。排行展示使用人数、正在使用人数、选择次数及用户访问日，不公开他人的逐条使用历史。
- 工坊列表只加载摘要；只保留当前作品详细记录。常驻对话最近 40 轮，之前记录按页读取，后台审计不裁剪。
- 上传限制单图 12 MB、2000 万像素以内；统一转换 WebP、去元数据并限制解码尺寸。图片懒加载，离开工坊释放预览 DOM；主题对话框关闭后释放预览。
- 空闲工作台轮询从 5 秒改为 15 秒，后台标签页停止轮询。项目、账户、收件人等辅助信息一分钟缓存；未打开的页面不反复重绘。
- 3D 眼睛使用固定容量 GPU 缓冲区；切换主题释放旧场景资源；隐藏的视频登录备用小球不创建 WebGL 场景。暂停的表情驱动停止动画帧调度，而不只是跳过绘制。

## 验证与边界

服务端拒绝跨账户素材、未经原生 imagegen 成功确认的结果、错误的阶段/领取令牌、未知 CSS 字段或脚本颜色值、错误 OSS 路径/公开范围以及迟到结果。确认必须对应作品当前版本。不会把用户输入变成任意 CSS、JavaScript 或应用发布指令。

设计图用于评审，不等同于真实页面截图。制作通过背景、限定颜色 token 和已有主题组件接入；自定义主题不会改业务页面结构或动态执行用户代码。生成可用性受本机执行器、账户图像生成额度、OSS 和 SMTP 状态影响，错误会显示并留痕。
